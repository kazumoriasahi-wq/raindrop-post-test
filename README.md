# Raindrop Post / あめつぶ郵便局

Draw temporary leafy paths to deliver raindrops to three flowers. Twelve calm gardens, changing winds, rocks, original synthesized garden music, Japanese/English UI, local stars and optional vibration on supported browsers.

Independent browser test game. Existing five game repositories are not modified. v1.1 integrates YouTube Playables SDK v1: readiness, cloud records, host pause/audio and language. Official certification remains pending. Custom SDK lab is a development fixture, not official certification.

Run `node serve.cjs` for a local preview on port 4190. Run `node tests.cjs`, `node solve-tests.cjs`, and `node music-tests.cjs`, `node host-tests.cjs` for checks.

Production files: index.html, style.css, host.js, engine.js, music.js, game.js. GUIDE.html contains play and device check instructions. No dependencies or external assets.
