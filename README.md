# Raindrop Post / あめつぶ郵便局

Draw temporary leafy paths to deliver raindrops to three flowers. Twelve calm gardens, changing winds, rocks, original synthesized garden music, Japanese/English UI, local stars and optional vibration on supported browsers.

Independent browser test game. Existing five game repositories are not modified. No YouTube Playables SDK or official certification in v1.0.

Run `node serve.cjs` for a local preview on port 4190. Run `node tests.cjs`, `node solve-tests.cjs`, and `node music-tests.cjs` for checks.

Production files: index.html, style.css, engine.js, music.js, game.js. GUIDE.html contains play and device check instructions. No dependencies or external assets.
